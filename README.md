# رفيق الحفظ — Rafeeq al-Hifz

تطبيق مجاني لحفظ القرآن الكريم ومراجعته، وقفٌ لوجه الله بلا إعلانات ولا اشتراكات.

A free, ad-free Quran memorization web app (sadaqah jariyah):

- Full Uthmani Mushaf (114 surahs, 6,236 ayat), works offline once loaded
- Listen with repetition (Alafasy, Husary, Minshawi, Abdul Basit, Ghamdi)
- Recitation practice with hidden words and browser-based Arabic voice checking
- Spaced-repetition review schedule; progress stays on the user's device

## Credits
- Quran text: The Noble Qur'an Encyclopedia (quranenc.com) via [quran-json](https://github.com/risan/quran-json), CC BY-SA 4.0
- Recitations: [EveryAyah.com](https://everyayah.com)

Voice checking is an approximation to support review; it does not replace learning from a qualified teacher.
